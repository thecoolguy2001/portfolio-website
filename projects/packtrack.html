Process

Developing a package tracking solution within the constraints of embedded hardware.

Surveyed tracking APIs (Ship24, AfterShip, TrackingMore, 17track) and landed on a provider-agnostic design — the user supplies the URL, key, and JSON fields.

Built a lightweight UART client for the FlipperHTTP devboard firmware — Wi-Fi connect and HTTP GET over GPIO at 115200 baud.

04

The config parser, URL templating, and JSON field extraction are pure C — tested on the host before ever touching the device.

June 19, 2025

Visual Design Direction

The Flipper Zero display is 128×64 pixels of monochrome — every pixel matters. The visual language for Pack Track is built on Flipper-native conventions so the app feels at home on the device, not like a transplant from a phone.

Native Flipper grammar

List-driven menus, dpad navigation, single-line headers — match the system apps so users don't relearn anything.

Status word over status code

"Out for delivery" reads better than "DEPARTED 04A." Five plain statuses — pending, transit, out, delivered, exception — cover every package.

Glyphs for status

Each status gets a tiny procedural glyph — filled dot delivered, ringed dot out for delivery, hollow ring in transit, dash pending, ✕ exception. No bitmap assets.

Refreshing is honest

HTTP calls take time on a Flipper — the header shows live progress ("Refreshing 2/5…") and plain results ("Updated", "No board found", "WiFi failed"), so it never looks frozen.

June 13, 2025

Solution

Pack Track is manual-first: your packages live in a plain packages.txt on the SD card and display instantly, fully offline. Add a Wi-Fi devboard running FlipperHTTP and your own tracking API key, and pressing RIGHT fetches live status for every package.

Quick Status Check

View package status instantly without reaching for your phone.

Provider-Agnostic

Nothing hosted, nothing hardcoded — point it at any tracking service with a URL, key, and JSON fields in config.txt.

Compact Display

Optimized UI for Flipper Zero's monochrome screen.

June 6, 2025

Target Users

Pack Track is for the slice of Flipper Zero owners who want their device to do real, daily work — not just RF tricks. Two patterns drive the design.

FT

The Flipper Tinkerer

Treats the Flipper as a daily tool, not a toy

Goals

  • Use the Flipper for real utility, not gimmicks
  • Quick info checks without unlocking a phone
  • Apps that respect Flipper conventions

Pain Points

  • Most third-party apps feel half-baked
  • Network-dependent apps rarely work reliably
FB

The Frequent Buyer

Has multiple packages in flight at any time

Goals

  • One screen, all packages, current status
  • Skip carrier websites that all look different
  • Quick "is it close?" answer

Pain Points

  • Three carriers means three apps
  • Notification spam without a unified view

June 3, 2025

Problem

Traditional package tracking requires a smartphone or computer to constantly go online to check shipping provider sites for delivery information, creating friction when users just want a quick status glance.

The challenge was bringing this utility to an embedded device with limited connectivity and display capabilities.
